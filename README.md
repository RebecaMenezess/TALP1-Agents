# TALP1 Agents

This repository contains 3 AI agents. Each agent has its own folder with the code, configuration, and setup instructions.

## Agents

### 1. Python Code Generator
Generates, validates, and iteratively improves Python programs from natural language descriptions.

### 2. Adversary Test Creator
Generates adversarial tests to challenge and stress-test existing code.

### 3. Code Refactor
Analyzes existing code and refactors it for readability, structure, and best practices.

---

For setup and usage instructions, open the folder of the agent you want to run and follow its `README.md`.
